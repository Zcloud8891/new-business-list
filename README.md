# Lane County & Oregon New Business List: public teaser pages

Static pages generated by `build.py` from the Oregon Secretary of State's public
"New Businesses Registered Last Month" dataset (data.oregon.gov, esjy-u4fc, public domain).
Only counts and a masked sample are published; owner names and street addresses are never written here.
Towing and roadside businesses are excluded.

- `python3 build.py` fetches the latest month, saves `summaries/YYYY-MM.json`, re-renders `docs/`.
- `python3 build.py --rebuild` re-renders from saved summaries only.
- `ops/monthly-rebuild.yml` (copy to `.github/workflows/` to enable) runs it daily on the 5th-18th and commits when a new month lands.
- Served by GitHub Pages from `docs/`.
